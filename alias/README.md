# ai-first

Alias sin scope de [`@falcux/ai-first`](https://www.npmjs.com/package/@falcux/ai-first).
No tiene código propio: depende del paquete real y expone el mismo comando.

```bash
npx ai-first init
npx ai-first audit
```

Es lo mismo que `npx @falcux/ai-first`, más corto. Los dos paquetes se
publican juntos y siempre en la misma versión. La documentación, el código y las
decisiones viven en el paquete real.

ni «Blueprint AI-First».
